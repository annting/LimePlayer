# 03 · UI 设计规范

> 本册是**界面侧唯一事实来源**：设计 token、组件规范、微动画基线、各页面与交互规格。
> 视觉原型见 [`../design/player-ui-mockups.html`](../design/player-ui-mockups.html)；功能意图见 [`01-功能说明.md`](01-功能说明.md)。
>
> **硬规则**：所有页面与组件**只引用本册的 token**，不写死数值；任何交互都必须带微动画（§4）。

---

## 1. 设计原则

**简洁轻便（首要原则）**：页面上只保留必要控件，一切能藏进手势、长按、底部弹层的操作都不常驻屏幕。

| 页面 | 常驻控件上限 |
|---|---|
| 库页 | 源切换 · 搜索 · 库 Tab · **一个**「排序 / 筛选」入口按钮（不做常驻筛选条） |
| 播放页 | 一行顶部信息 + 一行底部控制；字幕 / 音轨 / 倍速 / 画面比例**全部收进一个**底部弹层，不并排平铺按钮 |
| 详情页 | **一个**主按钮（播放 / 继续播放）+ 少量图标操作（收藏、标记已看）；技术信息折叠在展开区内 |
| 设置页 | 分组列表；二级设置进独立页；首页不铺开关 |
| 全部 | 删除一切装饰性元素：无广告位、无推荐位、无冗余文案 |

## 2. 设计系统（视觉基线）

### 2.1 主题

- **只做两套：亮色 + 暗色**。不做动态取色、多套色板、主题商店。
- 默认**跟随系统**（深色优先，观影场景）；设置里可切「跟随系统 / 亮色 / 暗色」三态。
- 实现上就是一份 `colorSchemeFor(isDark)`，无额外主题层。

### 2.2 色板

> **以下取值与 `design/player-ui-mockups.html` 的 CSS 变量一一对应，以设计板为渲染基准。**
> 品牌色以 app 图标（黄绿系 lime）为准 —— 旧稿里的薄荷绿 `#0FDC78 / #32F08C` 偏蓝、与图标不符，**已废弃**。

| Token | 亮色 | 暗色 | 对应 Material 3 角色 |
|---|---|---|---|
| `brand` 主色 | `#7CB342` | `#AED581` | primary |
| `brand-ink`（品牌色上的文字） | `#FFFFFF` | `#1B2A10` | onPrimary |
| `brand-soft`（选中底 / 强调底） | `#E8F0DB` | `rgba(174,213,129,.14)` | primaryContainer |
| `bg` 背景 | `#F4F6F9` | `#0B0D11` | background |
| `surface` 表面 | `#FFFFFF` | `#14171D` | surface |
| `surface-2` 次级表面 / 悬浮 | `#ECEFF4` | `#1C2028` | surfaceVariant |
| `surface-3` 轨道 / 未激活 | `#E1E5EC` | `#262B35` | surfaceContainerHighest |
| `border` 描边 / 分割线 | `#DCE0E7` | `#262C36` | outline |
| `border-strong` 悬停描边 | `#C6CCD6` | `#333A46` | outlineVariant |
| `text` 正文 | `#14171D` | `#E8EBF1` | onSurface |
| `text-2` 次级文字 | `#5A6472` | `#9AA3B2` | onSurfaceVariant |
| `text-3` 弱化说明 | `#8B94A2` | `#6B7484` | onSurfaceVariant（更低一档） |
| `success` / `warning` / `danger` | `#2F9E63` / `#D9822B` / `#D0453F` | `#4ED08A` / `#E8A33D` / `#F2685F` | — / error |
| `scrim` 播放器遮罩 | `rgba(0,0,0,.58)` | 同左 | scrim |

**使用规则**：
- 交互焦点、选中态、进度与播放指示一律用 `brand`；**不要**把 `brand` 用于大面积背景（观影场景会刺眼）。
- 播放页控制层是**恒定暗色**（`rgba(0,0,0,.34)` 玻璃底 + 白色文字），**不随主题切换**。
- 语义色只用于状态，不做装饰。

### 2.3 字体

| 层级 | 规格 | 用途 |
|---|---|---|
| `display` | 24sp / 600 | 页面主标题 |
| `headline` | 17sp / 600 | 区块小标题（「继续观看」「电影」） |
| `title` | 15.5sp / 600 | 卡片标题、弹层标题 |
| `body` | 14sp / 400 | 列表正文与分节正文 |
| `caption` | 11.5sp / 400 | 辅助说明（用 `text-3`） |
| `mono` | 13sp / 500 | **时间码与数字统一等宽**（JetBrains Mono），避免跳动 |

- 紧凑变体：海报卡标题 12.5sp、剧集行标题 13sp、徽标 10.5sp。
- 中文字体按 MiSans / 思源体系（思源黑体 / 苹方）适配。

### 2.4 间距 / 圆角 / 比例

| 项 | 规格 |
|---|---|
| 间距阶梯 | 4 / 8 / 12 / 16 / 24 dp |
| 页面左右安全边距 | 16dp（平板 24dp） |
| 圆角 | 8dp（控件 / 标签）· 12dp（卡片 / 浮层）· 999dp（胶囊） |
| 海报比例 | 库与搜索网格 2:3；剧集缩略图 16:9 |
| 触控目标 | 所有可点元素热区 **≥ 48dp** |
| 图标 | 24dp 线性图标，线宽 1.5–2；默认 `onSurfaceVariant`，选中 `primary` |

## 3. 组件规范

| 组件 | 规格 |
|---|---|
| **海报卡** | 2:3；圆角 12dp；标题区叠 24dp 底部 scrim 保证可读性；观看进度为 3dp 品牌色底条 |
| **按钮** | 主按钮 filled、高 48dp；次按钮 outlined；文字按钮用于低强调操作 |

| **列表行**（设置 / 详情） | 高 56dp；标题 16sp、副标题 12sp；尾部按需为 `Switch` / `Chevron` / 值文本；分割线左右 inset 16dp |

| **加载态** | 骨架屏 shimmer（**不用**全屏转圈） |
| **无海报占位** | 海报卡内显示 `surfaceVariant` 空白块，不发图片请求 |

## 4. 微动画基线（强制）

> 需求：按钮操作、菜单展开等**所有功能**都要有动画，且一律是**轻便微动画**。下表为强制基线，实现时不得省略。

| 交互 | 动画 | 时长 / 曲线 |
|---|---|---|
| 按钮按下 / 松开 | 缩放 `1.0 → 0.96`，松开回弹 | 90ms / 150ms，`spring(dampingRatio = 0.7)` |
| 图标按钮（播放·暂停·收藏） | 尺寸 `1.0 → 1.15 → 1.0` + 颜色过渡 | 180ms，`FastOutSlowInEasing` |
| 底部弹层展开 / 收起 | 自底部滑入 + `scrim` 淡入；高度变化用 `AnimatedContent` 平滑 | 250ms 入 / 200ms 出 |
| 菜单 / 下拉 / 排序选项浮层 | 缩放 `0.92 → 1.0` + 透明度 `0 → 1` | 150ms，`FastOutSlowInEasing` |
| Chip / 库 Tab 选中 | 背景 + 描边颜色过渡，下划线滑块横向滑动 | 200ms |
| 页面切换（库 → 详情 → 播放） | 共享元素（海报）+ 淡入淡出 / 横向位移 | 250ms |
| 列表 / 网格条目入场 | 首屏 `staggered 40ms/项`，位移 8dp + 淡入；分页追加不重复播放 | 200ms |
| 海报卡按下 | 缩放 `1.0 → 0.97` | 120ms |
| 排序 / 筛选结果刷新 | `animateItemPlacement` 重排 | 250ms |
| 播放页控制层显隐 | 位移 12dp + 淡入淡出 | 200ms |
| 进度条拖动 | 轨道高度 `3dp → 6dp` 平滑；预览浮层淡入 | 150ms |
| 九宫格锁屏 | 连线跟手；成功 150ms 淡出；错误红色抖动 300ms | 见 §7 |
| 加载态 | 骨架屏 shimmer（不用全屏转圈） | 循环 |
| 提示 / 错误 Toast | 自底部淡入上移，2s 后淡出 | 200ms |
| 开关（Switch） | 用 Material 3 系统默认动画，不自定义 | — |

- **硬约束**：时长一律 **≤ 300ms**；只做轻量微动画，**禁止**大面积位移、强弹性、视差、粒子等重动效；不做循环装饰动画（骨架屏 shimmer 除外）。
- **统一曲线**：入场 `FastOutSlowInEasing`、退场 `LinearOutSlowInEasing`。
- **无障碍**：当系统关闭动画（`ANIMATOR_DURATION_SCALE == 0`）时退化为瞬时切换。

## 5. 播放器页

### 5.1 状态机

| 状态 | 说明 | 进入方式 |
|---|---|---|
| 沉浸 Idle | 全屏视频，控制层隐藏 | 进入播放页 / 控制层 3s 无操作 |
| 控制层 Controls | 顶部 + 底部控制层可见 | 单击画面 |
| 拖动预览 Scrubbing | 进度条按下 / 拖动，预览浮层显示 | 按下进度条 |
| 设置抽屉 Sheet | 字幕 / 音轨 / 倍速 / 画面比例 | 底部控制层按钮 |
| 锁定 Locked | 隐藏控制层并屏蔽全部手势 | 控制层「锁定」按钮 |

### 5.2 布局（横屏）

```
┌──────────────────────────────────────────────┐
│ ←  标题 / 集数                                │  顶部控制层
├──────────────────────────────────────────────┤
│                                              │
│        ⟲10s          ⏯          10s⟳        │  中部控制
│                                              │
├──────────────────────────────────────────────┤
│   ┌───────── 预览浮层 ─────────┐              │
│   │  [sprite 切片 160×90dp]     │              │
│   │        01:23:45             │              │
│   └────────────────────────────┘              │
│  ━━━━━━━━━━━●━━━━━━━━━━━━━━━━━━━━            │  进度条
│ 01:23:45          ⟨设置⟩            2:04:10  │  底部控制层
└──────────────────────────────────────────────┘
```

- 底部控制层只保留：进度 + 时间 + 播放/暂停 + 快进快退 + **一个**⟨设置⟩按钮 + 全屏/锁定。
- 竖屏：视频 16:9 居中，下方留信息区（标题 / 集数 / 简介），复用同一控制层组件。
- `WindowInsets` 处理刘海 / 挖孔，视频在切口区域外绘制。

### 5.3 旋转

| 项 | 规格 |
|---|---|
| 默认 | 播放页 `sensor`（跟随系统自动旋转）；设置项提供「自动 / 仅横屏 / 仅竖屏」三态默认值，播放页可临时锁定 |
| 不重建 | 旋转时**保持播放器与媒体会话存活**，仅重排布局；实现上由 `configChanges` 自行响应尺寸变化，**不走系统 Activity 重建** |
| 恢复内容 | 保留播放位置、字幕 / 音轨 / 倍速选择、控制层显隐；若旋转时正在拖动进度条，则中断拖动但**不打断播放** |

### 5.4 进度条与预览条（核心规格，对应痛点 2）

**进度条**

| 项 | 规格 |
|---|---|
| 轨道高度 | 3dp；按下后展开为 6dp |
| 分段配色 | 已播放 = 品牌色；已缓冲 = 中性加深；未播放 = `border` |
| 触摸热区 | 32dp 高，外层 padding 保证可点击区域 ≥ 48dp |

**预览浮层（trickplay）**

| 项 | 规格 |
|---|---|
| 触发延迟 | 按下即显示，**≤100ms**，使用已预取分片，**不发起新网络请求** |
| 切片尺寸 | 160×90dp，圆角 12dp；时间戳等宽字体 12sp |
| 定位 | 水平跟随触点，左右各内缩 16dp，越界贴边；垂直固定在进度条上方 12dp |
| 更新节流 | 拖动中位移 ≥8dp **或** ≥60ms 才刷新一次，避免每帧重绘 |
| 切片换算 | `tileIndex = floor(timeMs / tileIntervalMs)`；`(col, row)` 由 `tiles.m3u8` 的列数与切片宽高反算 |
| 降级 | 无 trickplay → 只显示时间气泡；若用户开启「本地生成缩略图」→ 按需抽帧（优先复用已缓存帧） |

**提交策略（关键）**

| 操作 | 行为 |
|---|---|
| 轻点 tap | **立即** seek，UI 位置**乐观更新**，不等网络 |
| 拖动 drag | 拖动全程**不 seek**，只更新预览；**松手（ACTION_UP）才提交一次** seek |
| 长按 | 2× 临时倍速，松手恢复 |

> 理由：拖动过程中反复起流正是「点进度条卡 1 秒」的根因；commit-on-release 把 N 次起流压缩成 1 次。

### 5.5 手势

| 手势 | 行为 |
|---|---|
| 单击 | 切换控制层显隐 |
| 双击左 / 右 | 快退 / 快进（可配置 5s / 10s / 30s，默认 10s） |
| 左侧上下滑 | 亮度 0–100%，带渐变指示器 |
| 右侧上下滑 | 音量 0–100% |
| 水平滑 | seek（显示预览，松手提交） |
| 长按 | 2× 临时倍速 |

- 方向锁定：起始 24dp 内位移角 > 30° 判为纵向，否则判为横向。
- 锁定态（Locked）下**全部手势禁用**。

### 5.6 字幕 / 音轨 / 倍速 / 画面比例

入口：底部控制层⟨设置⟩→ 一个 `ModalBottomSheet`。

| 项 | 规格 |
|---|---|
| 字幕列表 | 内嵌轨 + 外挂轨（本机源自动发现同目录同名 `.srt/.ass/.ssa/.vtt`；服务端源取 `MediaStreams` 的 Subtitle 轨）+「关闭」 |
| 字幕样式 | 字号 / 颜色 / 描边色与宽度 / 底部边距 → 映射 `CaptionStyleCompat` |
| 音轨 | 列出语言 / 声道 / 编码并支持切换；不支持切换的源**置灰并给说明文案** |
| 倍速 | 0.5×–3.0×，步进 0.25×，记忆偏好；带音调补偿（`PlaybackParameters(speed, pitch = 1.0f)`） |
| 全局默认倍速 | 设置页配置，**新建播放会话自动套用**；播放页临时改速只影响**本次会话**，退出后回落默认值；长按的 2× 不写入默认值 |
| 转码流倍速 | 直放与本地源为纯客户端行为；服务端转码流可能不支持或需重开转码会话。不支持的源**置灰并说明**，不静默失效 |
| 画面比例 | 适应 / 填充 / 裁剪 / 原始 / 自定义缩放 |

### 5.7 连播与系统集成

| 项 | 规格 |
|---|---|
| 连播浮层 | 播至 **90%** 显示「下一集 + 10s 倒计时」，自动连播可关闭；提供「上一集 / 下一集」按钮 |
| 播放结束 | 回列表并置 `userData.isPlayed` |
| 屏幕常亮 | 播放中保持常亮，暂停 30s 后释放 |
| 画中画 | `onUserLeaveHint` 进入 PiP（16:9）；Android 13+ 用 `setAutoEnterEnabled` |
| 通知栏 | 封面 / 进度 / 上一集 / 下一集 / 快进快退 15s |
| 音频焦点 | 来电或其它应用抢占 → 自动暂停，恢复后提示继续 |
| 后台行为 | 默认暂停；详见 [`02`](02-技术规范.md) §6.7 |

### 5.8 错误与降级态

| 情况 | UI 表现 | 行为 |
|---|---|---|
| 直放失败 | 顶部小卡片「直放失败，正在切换转码…」 | 自动降级重试 |
| 转码失败 / 协商三档都不满足 | 全屏错误卡片 + 错误码 + 「重试」 | 写入诊断日志 |
| 服务器离线 | 断网占位 + 「重试」 | 恢复后自动重连 |
| 资源不存在（404） | 「该视频已不存在」 | 提供「从库中移除」 |
| 无可用音轨 / 字幕 | 按钮置灰 + 说明文案 | — |

### 5.9 平板与折叠屏

- 平板横屏：控制层左右内缩 48dp（防边缘误触）；预览切片放大到 200×112dp。
- 分屏 / 折叠屏：由 `WindowSizeClass` 驱动布局切换，**不新增专用代码路径**。

## 6. 库浏览 / 搜索 / 详情

### 6.1 库浏览页

- 结构：顶部 AppBar（**源切换** + **搜索入口**）→ 二级栏（媒体库 Tab）→ 内容网格 + 右下角**单一「排序 / 筛选」入口按钮**。
- 排序 / 筛选入口（合并为一个按钮）：
  - 点击弹出**同一个** `ModalBottomSheet`：上半为排序维度（§6.3 全部维度，支持主序 + 次序，当前态高亮），下半为筛选条件；
  - 有生效的筛选或非默认排序时，按钮显示**数量徽标**；弹层内提供「恢复默认」一键清空；
  - 结果**本地瞬时完成、无 loading**。
- 网格：`LazyVerticalGrid`，海报卡（2:3）+ 标题 + 观看进度角标；长按进入多选（批量标记已看 / 收藏）。
- 滚动：服务端增量分页；排序 / 筛选作用在已同步的本地索引上，**不触发网络**。
- 空态三分：库为空 / 未登录 / 同步中，分别给引导文案。

### 6.2 搜索页

- 入口：库页顶部搜索框 → 独立搜索页（或 Material 3 `SearchBar` 内联展开）。
- 结构：输入框（自动聚焦并唤起输入法）→ 最近搜索 chips → 输入即搜的结果网格。
- 交互：debounce 200ms；**输入即搜**，无需点「搜索」按钮；过期查询被丢弃。
- 结果：复用库页网格 + 排序 / 筛选；多结果按 [`02`](02-技术规范.md) §6.5 的权重排序。
- 状态机：`历史（输入为空）→ 搜索中（骨架屏）→ 有结果 → 无结果（空态）→ 索引未就绪（顶部提示 + 服务端兜底结果）`。
- 最近搜索：本地保存最近 N 条并可清空；点击回填并立即检索。
- 关键词高亮：命中词在标题中高亮（可选增强）。

### 6.3 详情页

- 结构：海报背景 + 标题 / 评分 / 年份 / 时长 / 官方分级 → 「播放 / 继续播放」主按钮 → 剧集列表（分季）→ 简介 → 演职员 → **技术信息（折叠）**。
- 主按钮文案随观看状态变化：未看「播放」/ 在看「继续播放 · 剩 xx 分」/ 已看「再次播放」。
- 剧集：分季 Tab + 每集缩略图 + 简介 + 进度条 + 已看标记；点集直接进播放器并连播。
- 技术信息：容器 / 视频编码 / 音频编码 / 码率 / 分辨率 / 文件大小——服务端条目与本机文件**统一展示**，便于排查「为什么某文件播不了」。
- 操作：收藏、标记已看 / 未看、播放方式选择（自动 / 强制直放 / 强制转码）。

### 6.4 底部导航与多库 / 多服务器的展示

单台服务器通常有多个媒体库（电影、电视剧、动漫、纪录片、综艺、家庭视频…），本项目再叠加多服务器与「本机」源。手机采用**底部导航（一级）+ 库 Tab（二级）**两级结构，与设计板 ① 的 `.bottomnav` 一致：

| 层级 | 内容 | 手机竖屏 | 平板 / 折叠屏 |
|---|---|---|---|
| 一级 底部导航 | 首页 / 媒体库 / 搜索 / 设置 | 底部 `NavigationBar` 4 tab | `NavigationRail` 顶部常驻 |
| 二级 库切换 | 当前源下的库 + 「全部」 | 顶部**横向库 Tab**，粘性置顶 | Rail / Drawer 内「库」分组 |
| 三级 内容 | 海报网格 + 排序 / 筛选 | 网格 | 网格（列数更多） |

**四个底部 tab 的内容与里程碑**：

| tab | 内容 | 归属 |
|---|---|---|
| **首页** | 聚合首页：顶部「继续观看」卡片 + 各库一行横滑海报（「查看全部」） | M3（继续观看依赖 2-3 进度上报） |
| **媒体库** | 库 Tab + 海报网格（当前库页） | ✅ M1 已落地 |
| **搜索** | 中文 / 拼音 / 首字母搜索 | M3 |
| **设置** | 服务器管理 + 播放偏好 + 关于 | M5 |

**库 Tab 规则**（手机 · 媒体库 tab 内）：条目 = `全部` + 各库（图标 + 名称 + 条目数）。切换在**本地已同步索引**上瞬时完成。库 ≤5 均分不滚动；>5 横向滚动并给渐隐边缘提示。

**多服务器规则**：
- **同一时刻只显示一个源**；不做多服务器库混排（避免 ID 冲突与语义混乱）。
- 离线时展示上次同步快照并标注「离线」。
- 「本机」源不分组库，直接以目录 / 文件夹作为二级项（**L2**；M0–M5 不出现任何「本机」入口）。
- 源未登录 → 一级红点提示 + 「去登录」；库为空 → 默认隐藏空库（可设置显示）；库数量 > 8 且手机竖屏 → 自动回退抽屉模式，避免 Tab 挤压。

## 7. 应用锁锁屏页

| 项 | 规格 |
|---|---|
| 布局 | 居中 3×3 九宫格；标题「绘制解锁图案」；失败文案行；底部辅助操作行（生物识别 / 用 PIN 解锁 / 忘记图案？） |
| 几何 | 点直径 12dp、连线 4dp；**命中半径 24dp**；外圈保护环 36dp；点间距按屏宽自适应（左右安全边距 24dp） |
| 状态机 | `idle → drawing → verifying → success（150ms 淡出进入）｜error（红色抖动 300ms）｜cooldown（倒计时期间禁用绘制）` |
| 颜色 | 空闲点 `outline`；已连点 / 连线 `primary`；错误态 `danger`；背景 `background` |
| 规则 | 至少连 4 点才可提交；弱图案（Z / L / 直线等）在设置保存时拒绝 |
| 生物识别 | 进入即弹系统指纹 / 人脸；失败自动回落图案，不阻塞 |
| 冷却态 | 显示「尝试过多，请 30s 后重试」，期间九宫格降透明度且不可交互 |
| 忘记路径 | 底部「忘记图案？」→ 弹窗说明（配备用 PIN 则引导用 PIN；否则仅能清除应用数据） |

> 实现注意：命中判定与绘制必须使用**同一套几何口径**（以正方形画布边长为基准）；点的半径按 **dp → px** 换算，不要写成裸像素。

## 8. 设置页

- **结构**：分组滚动列表；组标题 12sp 小字；组内为 56dp 列表行。
- **分组**（完整清单见 [`01`](01-功能说明.md) §6）：
  - **外观**：主题（跟随系统 / 亮色 / 暗色，**仅此一项**）
  - **播放**：默认倍速 · 保持后台播放 · 双击快进 / 快退间隔 · 自动连播下一集
  - **画面**：屏幕方向 · 默认画面比例 · 字幕样式
  - **隐私**：应用锁 · 解锁方式 · 回前台解锁宽限期 · 后台遮挡任务快照
  - **预览**：本地生成缩略图
  - **搜索**：模糊音 · 繁体 / 简体互搜
  - **网络**：明文 HTTP · 信任自签证书
  - **源**：服务器管理（L2 再加「本机视频目录」）
  - **关于**：版本与许可声明（含 LGPL / FFmpeg）
- **行样式**：标题 + 一句话副标题（解释作用）；尾部控件按类型为 `Switch` / `Chevron`（跳二级页）/ 当前值文本。
- **危险操作**：「清除应用数据」用 `danger` 文字色，点击弹二次确认对话框。
- **二级页**：服务器管理、字幕样式、关于页。

## 9. 添加服务器与登录

**流程**：选源类型 → 填地址 → 测试连接 → 输入凭据 → 拉取库 → 完成。

| 步骤 | 规格 |
|---|---|
| 选源类型 | 卡片单选；每张带图标 + 一句说明。**M1 只有 Emby 一张**；「本机视频」卡片 L2 才加 |
| 填地址 | 输入框智能补全 `http://`；端口默认 Emby `8096` / 飞牛 `8005`；「测试连接」实时探测并回显**服务器名**；未探测成功不允许进下一步 |
| Emby 登录 | 账号 + 密码；成功即返回令牌 |
| 飞牛登录 | **M4 只有「账号密码」一个分段控件**；NAS 账号授权 / 扫码登录到 **L1** 再补，M4 阶段**不显示、不置灰、不做占位** |
| 错误态 | 地址不可达 / 认证失败 / 端口或路径前缀错误（404）**三类分别提示**，并给「修改地址」入口 |
| 完成 | 拉取媒体库 → 进入库页并高亮新添加的源 |
| 首启引导 | 无任何服务器时展示引导空态（文案 + 「添加服务器」按钮），不显示空的库页 |

## 10. 无障碍与适配

| 项 | 要求 |
|---|---|
| 动画 | 系统关闭动画时全部退化为瞬时切换 |
| 触控 | 所有可点元素热区 ≥ 48dp；图标按钮配 `contentDescription` |
| 对比度 | 正文与背景对比度满足 WCAG AA；深色主题下正文不低于 `#E5E5E5` |
| 长文 | 标题最多 2 行，超出省略；简介可展开 |
| 平板 / 折叠屏 | 由 `WindowSizeClass` 驱动，不写死宽度断点 |
