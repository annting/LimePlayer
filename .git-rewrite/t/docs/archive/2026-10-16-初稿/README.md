## 为什么会保留而不是删除

- 这些文件记录了**设计推演的过程**与**调研依据**（第三方资料、官方文档链接、实测口径），后面遇到「当时为什么这么定」的问题时，答案在这里。
- 评审报告是唯一一份把「问题 → 位置 → 改法」写全的记录，后续新增功能时可以参考同样的检查视角。
- 需求前提若有变化（例如用户决定不再支持本机文件），可以对照初稿快速判断哪些设计是耦合的。
