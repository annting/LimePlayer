## 1. 开发流程

### 1.1 基本工作流（规格先行）

```
需求 → 改文档（01/02/03 中相应的一册）→ 拆任务（本册 §3）
     → 【红】先写会失败的测试 → 【绿】最小实现让它通过 → 【重构】
     → 跑该模块的测试命令 → 提交 → 更新本册进度看板
```

- **规格先行**：任何行为、契约、界面规则的变更，**先改文档再改代码**。代码与文档冲突时以文档为准。
- **红绿节奏不得省略**：每个任务都必须是「运行确认失败 → 实现 → 运行确认通过 → 提交」。这是可验收的前提。
- **任务粒度**：一个任务 = 一次提交，且**独立可测**。任务之间不共享未提交的半成品。
- **单一事实来源**：技术契约在 `02`，界面规格在 `03`，接口细节在 `05`。不要在计划里复述它们，用链接引用。

### 1.2 提交规范

| 项 | 约定 |
|---|---|
| 频率 | 每个任务结束提交一次 |
| 消息 | `<type>(<scope>): <做了什么>`，type ∈ `feat/fix/docs/refactor/test/chore` |
| 示例 | `feat(emby): add emby adapter, mapper and device profile` |
| 首次 | 仓库若尚未初始化，**第一个任务先 `git init`** 并提交 `.gitignore` |

### 1.3 测试策略

| 层级 | 覆盖对象 | 工具 |
|---|---|---|
| 纯 JVM 单测 | 领域逻辑：`Ticks` 与单位换算、排序引擎、搜索索引与权重、播放协商决策表、地址归一化与登录错误映射、DTO 映射、trickplay 时间 → 分片换算 | JUnit4 + Truth |
| Android 单测 | Room（DAO / 映射 / 索引）、DataStore 读写与异常回退、Compose 组件几何 | Robolectric / Compose 测试 |
| 集成测试 | 各源适配器对本地 mock server 的**请求构造与解析**（含取库走 `/Views`、列表不请求 `People`、相对转码地址被拼成绝对 URL、图片 URL 不带令牌） | MockWebServer |
| UI 流程测试 | 首启流程（添加服务器 → 测试连接 → 登录 → 进库页）、排序筛选交互、搜索状态机、播放器进度条拖动、九宫格解锁 | Compose 测试 |
| 人工验收 | 真机对 Emby / 飞牛 / 本机三类源各跑一遍痛点场景（见 [`01`](01-功能说明.md) §7） | 手工 |

**覆盖率要求**：不设百分比门槛；但**每个任务必须为它的行为给出测试**，没有测试的任务不算完成。

### 1.4 AI 代理执行约定

| 项 | 约定 |
|---|---|
| 必读顺序 | `README` → 本册（当前里程碑 + 本约定）→ `02`（§3 模块 / §4 模型 / §5 接口 / §9 硬约束）→ 需要时 `05`、`03` |
| 禁止 | 不得在未读 `02` §9 硬约束的情况下写实现；不得跳过红绿节奏；不得引入 `02` 未列出的依赖 |
| 越界 | 发现文档与代码冲突 → **停下来改文档**，不要两边各写一份 |
| 执行方式 | 参考实现按「一任务一子代理、任务间由主代理审查」的方式效果最好；若本机未安装相应子技能，则**按任务顺序串行执行**，每个任务跑完测试再进下一个 |
| 收尾 | 每个任务结束时：更新本册 §4 进度看板 + 在 `.workbuddy/memory/` 追加一行工作日志 |

### 2.1 执行顺序与依赖

```
M0 ────────────────────────────┬──────────► M4（飞牛登录与请求参数）
                               │
M1 ──► M2 ──► M3 ──────────────┴──► M5 ──┬──► L1（飞牛授权登录）
        │                                 └──► L2（本机视频文件）
        └──► M4 的骨架可复用（:source:httpapi），可与 M3 并行
```

- **M0 不产出代码，但必须先做**：它决定 M4 的登录与请求参数。可与 M1 并行。
- **M1 是整个项目的地基**：`core:*` 与 `source:httpapi` 的契约都由 M1 固定，M2–M5 与 L1/L2 全部建立在其上。
- **L1 只改 `:source:jellyfin` 的登录流程**，不动共享骨架；**L2 只新增 `:source:local` 模块**，不动上层。
