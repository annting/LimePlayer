# LimePlayer 文档索引

> 青柠视频播放器（Lime Video Player）——个人自用的 Android 视频播放器。
> 目标是**无广告、界面精致、格式兼容性好**，并把 Emby / 飞牛影视官方客户端做不到的几件事做对：
> 进度条实时缩略图预览、无卡顿 seek、本地强排序、全局默认倍速、中文友好搜索。

**本文件是唯一入口。** 无论你是人还是 AI 代理，都先读这一页，再按下面的地图跳到需要的分册。
**不要**从代码或归档文件开始读。

## 4. 关键决策速查（别重复讨论）

| 决策 | 结论 | 出处 |
|---|---|---|
| 三种源的关系 | 飞牛影视使用 **Jellyfin 兼容协议**，与 Emby 共用一套 REST 骨架 + 两个薄适配层，**不做两套独立客户端** | `05` §5 |
| 飞牛登录方式 | M4 **只做「影视账号密码」**；NAS 账号授权 / 扫码 / 一次性授权码全部后置到 L1 | `01` §5.3 |
| Emby 登录方式 | 恒为账号密码（`/Users/AuthenticateByName`），无授权流程 | `05` §2 |
| 本机视频 | 整体后置到 **L2**；M0–M5 只需保证 `MediaSource` 抽象与 `SourceType.LOCAL` 就位 | `04` §3 |
| 排序 | 服务端 `SortBy` 不含文件大小/码率/分辨率 → **客户端本地排序是唯一事实来源** | `02` §5.3 |
| 搜索 | 服务端 `SearchHints` 对中文几乎无效 → **以客户端本地索引为主**，服务端仅兜底 | `02` §5.5 |
| 主题 | 只做**亮色 + 暗色**两套（默认跟随系统），不做动态取色 / 主题商店 | `03` §2.1 |
| 多服务器 | 同一时刻**只显示一个源**，不做多服务器库混排 | `03` §6 |
| 时间单位 | 领域层统一 `Ticks`（100ns）；只在 Room 边界与播放层边界显式互转 | `02` §4.4 |
| 凭据存储 | 图案 / PIN 经 PBKDF2 派生、由 Keystore 保护的对称密钥加密后落盘，**明文不落盘** | `02` §5.6 |
| 后台行为 | **默认切后台即暂停**；「保持后台播放」默认关闭 | `02` §5.7 |
| 局域网发现 | **不做**自动发现（局域网内 Emby/Jellyfin 会互相干扰扫描），一律由用户显式添加 | `05` §1 |
| 源装配点 | `SourceFactory` 放在 `:feature:server`——因为 `:source:*` 之间不允许互相依赖 | `02` §3.2 |

3. **一个事实只写一处**。同一结论不要在多个文件里各写一遍——其他文件用链接引用。
4. **编号稳定**：分册编号（01–05）与章节号（§x.x）一旦发布不重排；新增内容往后加或加子号（如 §5.3.1）。

7. **归档不删除**：被替代的文档移入 `archive/<日期>-<主题>/`，保留可追溯性。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| **Emby / Jellyfin** | 两个媒体服务器。Jellyfin 是 Emby 3.5 的分支，API 同源，差异集中在鉴权头与转码参数命名 |
| **飞牛影视 / fnOS** | 飞牛的 NAS 系统与其影视应用。影视应用走 Jellyfin 兼容协议，默认端口 `8005` |
| **Ticks** | Emby/Jellyfin 的时间单位，1 tick = 100ns，1 秒 = 10,000,000 ticks |
| **trickplay** | 服务端预生成的缩略图精灵图（tile），用于进度条拖动时的实时预览 |
| **DirectPlay / DirectStream / Transcode** | 三种播放方式：原文件直放 / 仅换容器或音轨（视频不重编码）/ 完整转码 |
| **DeviceProfile** | 客户端在 `PlaybackInfo` 请求里声明的解码能力，服务端据此决定直放还是转码 |
| **SAF** | Android Storage Access Framework，用于访问 MediaStore 之外的目录 |
| **PiP** | 画中画（Picture-in-Picture） |
| **FTS4 / unicode61** | SQLite 全文检索虚表与其分词器；本项目用它在中文逐字间插空格以支持任意位置子串匹配 |
| **pinyin4j** | 拼音库（BSD），用于生成拼音全拼与首字母索引。原计划指定的 TinyPinyin 只发在已关停的 JCenter，Central 拿不到，已替换 |
| **Keystore** | Android 系统密钥库，本项目用它保护加密凭据的对称密钥 |
| **DoD** | Definition of Done，里程碑验收口径 |
| **痛点 1–6** | 见 `01-功能说明.md` §1，需求来源可追溯到这六条 |
