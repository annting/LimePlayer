## B. 播放器专项（重点）

### 播放内核
- **Media3 ExoPlayer 1.11.1**，通过 `core:playback/PlaybackEngine.kt` 接口抽象，预留 libmpv 扩展点
- HLS 扩展已引入（转码流用 `APPLICATION_M3U8`），**无 DASH**
- 缓冲调参：minBuffer 15s / maxBuffer 60s / bufferForPlayback 1.5s；seek 策略 `CLOSEST_SYNC`（对齐关键帧，拖动起播最快）
- 音频焦点 `handleAudioFocus=true`，耳机拔出自动暂停

### 播放场景
| 场景 | 支持 | 实现 |
|---|---|---|
| 在线点播 | ✅ | Emby / Jellyfin / 飞牛（fnOS） |
| 局域网文件 | ✅ | SMB（jcifs-ng + 本机 HTTP 代理 `SmbStreamServer`） |
| HLS 转码流 | ✅ | `PlaybackPlan.Transcode` |
| 直播 / 短视频信息流 / 监控流 | ❌ | — |

### 格式与分辨率
- 支持 **4K / HDR**（`core:model/Models.kt#L229-L237` 的 `ClientCapabilities` 有 `supportsHdr`、`maxWidth/maxHeight` 字段，向服务端声明能力）
- 杜比（Dolby）未见相关处理
- 视频编码由 `DeviceProfile` 向服务端声明，直放失败自动降级转码

### 功能清单
| 功能 | 状态 | 说明 |
|---|---|---|
| 倍速 | ✅ | 0.5x–3.0x，会话级（退出回落默认） |
| 字幕 | ✅ | 外挂 + 内嵌；引擎只抛 cue 文本，**UI 层自绘**（`PlayerSubtitleLayer`），支持字号/颜色/描边/位置 |
| 弹幕 | ❌ | 无 |
| 画中画（PiP） | ✅ | 按钮触发；隐私模式下禁用 |
| 后台播放 | ✅ | `PlaybackService`（MediaSessionService，foregroundServiceType=mediaPlayback） |
| 投屏 | ❌ | 无 Cast |
| 下载缓存 | ❌ | 无离线下载 |
| DRM | ❌ | 无 |
| HLS | ✅ | 转码流 |
| DASH | ❌ | 无 |
| 循环 | ❌ | 无 |
| AB 循环 | ❌ | 无 |
| 连播 | ✅ | 90% 弹出下一集 + 10s 倒计时，可取消 |
| Trickplay 预览 | ✅ | 拖动进度条显示缩略图（服务端预生成） |
| 画面比例 | ✅ | 适应 / 填充 / 裁剪 / 原始 |
| 音轨/字幕轨切换 | ✅ | `selectTrack` 支持关闭 |

### Surface
**TextureView**（非 SurfaceView）—— 代码注释明确说明原因：SurfaceView 的画面在独立图层，`setRotation` / `graphicsLayer` 只转 View 不转视频，无法支持假横屏旋转。见 `PlayerScreen.kt#L509-L512`。

### 列表播放模式
**单实例切换**。引擎由前台服务进程级持有（`onCleared` 只 `stopSession` 不 `release`），无抖音式多实例同时播放。

### 已知问题
完整案卷在 `docs/07-问题排查.md`，共 9 条，**全部 ✅ 已解决**。与播放相关的痛点：
- **切后台回来黑屏** → BUG-2026-008：未举 `FLAG_KEEP_SCREEN_ON`，播放中约 30s 自动息屏。已修（`keepScreenOn` 跟随 `isPlaying || BUFFERING`）
- **横屏倒立 180°** → BUG-2026-007：物理旋转 + 内容旋转叠加。已修（合并判据，系统已横屏时内容不再转）
- **控制层压状态栏** → BUG-2026-006：inset 被上游消费，`statusBarsPadding()` 恒为 0。已修（读原始 `WindowInsets.statusBars.getTop`）
- **切后台自动暂停 / 回前台续播** → 应用锁开启时只解锁不自动起播（用户反馈"刚解完锁视频自己动起来"）

## C. UI 现状

### 设计规范
- **有完整设计规范**：`docs/03-UI设计规范.md` + UI 审查报告 `docs/09-UI审查报告-2026-10-27.md`
- **Design Token 集中管理**在 `:core:designsystem`：
  - `Color.kt` — 亮/暗双套，WCAG AA 对比度校准过
  - `Dimens.kt` — 8dp 网格间距阶梯
  - `Type.kt` — 字号阶梯
  - `Shape.kt` — 圆角体系（8/12/999dp，禁胶囊）
- 自定义组件 14 个（`AppChip` / `Field` / `FloatingBottomNav` / `SettingsComponents` 等）

### 颜色/字号/间距散落情况
**高度集中**。全项目 `feature/` 下硬编码 `Color(0x...)` 仅 **1 处**（`ServerLogo.kt`，服务器品牌色）。播放器页有独立的 `PlayerTokens`（不跟随主题反转，因为叠在视频画面上）。

### 播放控制条套数
**1 套**。所有控制逻辑集中在 `PlayerScreen.kt` 的 `PlayerControls` 函数内（顶栏 + 右侧 PiP/旋转 + 底部进度条/时间/按钮行 + 快捷浮层）。

### 深色模式 / 横竖屏 / 折叠屏
- **深色模式**：✅ 支持，`isSystemInDarkTheme()` 自动切换，双主题色板
- **横竖屏**：采用**假横屏方案**——Manifest 全局锁竖屏，播放页通过 `graphicsLayer { rotationZ = 90f }` + 宽高对调实现横屏，退出无旋转动画。平板/折叠屏（`windowIsLandscape`）时不重复转
- **折叠屏适配**：有 `windowIsLandscape` 判断守卫，但未见专门的折叠屏展开态布局测试

### Material3 / Design System
- **全面接入 Material3**（47 个文件使用 `material3`），通过 `MyPlayerTheme.kt` 统一 `colorScheme` + `typography` + `shapes`
- 自定义 Design System 在 M3 之上扩展（`LocalAppColors` 提供 `brandInk` / `text3` / `surface2` 等 M3 槽位装不下的语义）

## G. 针对性建议（按优先级）

1. **P0 — 线上可观测性**：至少接入 Crashlytics（免费、零代码量），否则上线后崩溃只能靠用户口述复现
2. **P0 — PlayerScreen 拆分**：1489 行已超过单人维护阈值，`VideoSurface`/`GestureLayer`/`PlayerControls` 已有 private 函数边界，拆成独立文件即可
3. **P1 — 混淆 + Baseline Profile**：M5 前补 `proguard-rules.pro`（kotlinx.serialization `@Serializable`、Media3、OkHttp keep 规则），并生成 Baseline Profile 改善冷启动
4. **P1 — CI 门禁**：GitHub Actions 跑 `./gradlew test` + `assembleDebug`，防止回归
5. **P2 — 播放能力按需补齐**：投屏（Cast）和下载缓存是媒体播放器常见诉求，若产品定位需要可规划
