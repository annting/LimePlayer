

# 03 · UI 设计规范 (Expressive 定制版)

## 1. 设计原则与风格
- **风格**：年轻潮流、Material 3 Expressive。
- **视觉**：颜色活泼、形状克制但动效充满表现力。
- **简洁**：不做冗余装饰，但视觉焦点（如播放按钮、选中态）必须有冲击力。

## 2. 设计系统 (Tokens)

### 2.1 主题与色板
- 只做亮色 + 暗色，不做动态取色。
- **品牌色 (Brand)**：青柠绿（Lime）。
  - 亮色主色：`#4D7C0F`；暗色主色：`#AED581`。
  - **亮色主色为什么不是 `#7CB342`**（2026-10-27 改）：`#7CB342` 配白字只有 **2.50:1**，AA 不达标；
    `#4D7C0F` 同色相压亮度后 = 白字 **4.99:1** / 页面底 4.61:1。见 `ui-prototype/v2/UI优化方案.md` §1.1。
  - **使用规则**：允许在“服务器选中卡片”、“悬浮导航选中项”使用大面积品牌色背景，但内部文字必须用深色 `brand-ink`（暗色 `#1B2A10`，亮色 `#FFFFFF`）以保证对比度。
  - 其他卡片默认用 `surface`，靠微弱的描边区分。
- 背景、表面、文字颜色严格沿用原规范（bg, surface, text 等）。

### 2.2 圆角规范（重大更改）
- **悬浮导航栏**：`999dp`（唯一允许的胶囊形）。
- **普通卡片 / 底部弹层**：`12dp`。
- **按钮 / 输入框 / Chip 标签 / 图片**：`8dp`。
- *严禁使用除了悬浮导航之外的其他胶囊形或超大圆角。*

### 2.3 字体与间距
- 沿用原规范（8dp 网格，24/17/15.5/14/11.5 字体阶梯）。

## 3. 组件规范

### 3.1 悬浮底部导航 (Floating Navigation)
- **样式**：类似支付宝最新版，悬浮在内容上方 16dp 处，底部留出安全区。
- **形状**：全圆角胶囊 (`999dp`)。
- **背景**：`surface` 加上轻微阴影。
- **选中态**：**图标与文字变 `primary` + 图标上方一枚 5dp 指示点**；四项**都常显标签**、结构完全一致
  （指示点用透明占位，不改变高度）。**不再画背景色块、不再做图标缩放弹跳** ——
  色块撑大 + 文字展开会把图标从格子中心推开，切换时整排都在动（2026-10-27 改，见 UI 优化方案 L7）。

### 3.2 按钮 (Buttons)
- **主按钮**：Filled 样式，背景 `primary`，高 48dp，圆角 8dp。
- **次按钮**：Outlined 样式，背景透明，边框 1dp `border`，高 48dp，圆角 8dp。
- **文字按钮**：仅用于低强调，颜色为 `primary` 或 `danger`。

### 3.3 标签与选项 (Chips)
- 高 32dp，**圆角 8dp（不再是胶囊）**。
- 选中态：背景 `primaryContainer` 或 `primary`，描边变粗。

### 3.4 列表与输入框
- 输入框：圆角 8dp，背景 `surface-2`，无边框或极细边框。
- 列表行：高 56dp，开关使用 M3 默认样式。

## 4. 微动画基线 (Material 3 Expressive)
*长度限制放宽至 400ms，允许轻量级弹性。*
- **按压反馈**：缩放 1.0 → 0.95 → 1.0，使用 `spring(dampingRatio = 0.6, stiffness = Spring.StiffnessMedium)`。
- **页面切换**：共享元素 + 淡入淡出。
- **悬浮导航栏切换**：选中背景块使用 `animateColorAsState` 过渡，图标带轻微弹跳。

## 5. 播放器页
- 结构已定，不做重构。仅需将硬编码颜色替换为规范中的 Token，确保亮/暗主题切换时，底部控制栏的背景遮罩 (scrim) 正确。
