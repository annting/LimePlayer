# 01 · 功能说明

> 本册回答「**这个 App 做什么、怎么用、边界在哪**」，不涉及实现方式。
> 实现与契约见 [`02-技术规范.md`](02-技术规范.md)，界面细节见 [`03-UI设计规范.md`](03-UI设计规范.md)。

- 应用名：**青柠视频播放器 / Lime Video Player（LimePlayer）**
- 定位：个人自用 / 学习开源。不上架、无账号体系、不内置任何内容源
- 平台：**Android 手机与平板**（不做 TV / 车机 / 遥控器适配）
- 文档建立：2026-10-16

---

## 1. 背景与痛点

需求全部来自真实使用中的不满，编号在全套文档中保持一致，便于追溯：

| 编号 | 痛点 | 现状 |
|---|---|---|
| **痛点 1** | VidHub 收费，且部分视频无法播放 | 需要免费、格式兼容性更好的播放器 |
| **痛点 2** | Emby 官方 App 播放体验差：只能点按钮快进几秒，**无法拖动进度条实时预览**；点击进度条位置约 1 秒卡顿（同手机、同网络下 VidHub 无此问题） | 本项目核心差异化点 |
| **痛点 3** | 飞牛影视 App 排序能力弱：无法按「视频时长」「文件大小」等排序 | 服务端固有缺陷，必须客户端补足 |
| **痛点 4** | 第三方 App 普遍有广告、界面粗糙 | 需要无广告、精致的界面 |
| **痛点 5** | Emby 无法设置全局倍速：每次播放都要手动调 | 需要「默认倍速」并自动套用到每次播放 |
| **痛点 6** | Emby 官方搜索对中文支持极差，中文标题基本搜不到 | 需要客户端本地索引补足中文 / 拼音 / 首字母搜索 |

---

## 2. 目标与非目标

### 2.1 目标

1. 一个**无广告、界面精致**的 Android 播放器，手机与平板为主。
2. 主链路接入两类服务端源：**Emby 服务器**、**飞牛影视（fnOS）**；**本机视频文件**后期迭代支持。
3. 针对痛点做差异化：进度条实时缩略图预览、毫秒级无卡顿 seek、强大的本地排序与筛选、全局默认倍速、中文友好搜索。
4. **默认安全与省电**：应用级九宫格图案锁（启动 / 回前台解锁）；默认切后台自动暂停播放。
5. 播放页横竖屏跟随手机旋转自动切换，并支持手动锁定。

### 2.2 非目标（明确不做，避免范围蔓延）

| 不做的事 | 说明 / 归属 |
|---|---|
| Android TV / 盒子 / 车机的大屏与遥控器适配 | 不做 |
| 直播（IPTV）、音乐库、相册、下载离线包 | 不做 |
| Plex、SMB / WebDAV / NFS 目录直挂 | 不做（作为后续可插拔源考虑） |
| 商业上架、多语言国际化、账号体系 | 不做（定位个人自用） |
| 飞牛**授权式登录**（NAS 账号 OAuth / 扫码 / 一次性授权码） | 后期迭代 **L1** |
| **本机视频文件**播放 | 后期迭代 **L2** |
| 复杂主题系统（动态取色 / 多套色板 / 主题商店） | 只做**亮色 + 暗色**两套 |
| 多服务器内容混排 | 不做，同一时刻只显示一个源 |
| 局域网自动发现服务器 | 不做（局域网内 Emby/Jellyfin 会互相干扰扫描） |

## 3. 用户与使用场景

**用户画像**：一个人，自己搭了 NAS（Emby 或飞牛影视），手机/平板想看家里的电影与剧集，在意界面干净、播放流畅、能按自己的方式排序和搜索。

| 场景 | 期望行为 |
|---|---|
| 首次使用 | 添加服务器 → 测试连接回显服务器名 → 账号密码登录 → 直接看到库与海报 |
| 日常浏览 | 打开即解锁（图案锁）→ 顶部切库 → 网格浏览 → 本地瞬时排序/筛选 |
| 找片 | 搜「三体」「santi」「st」都能命中；中文任意位置子串都能搜到 |
| 播放 | 起播快、能拖动进度条看到缩略图预览、松手才跳转、不卡顿 |
| 追剧 | 播到 90% 自动提示下一集并连播；进度自动回传服务器 |
| 切走 | 切后台自动暂停（省电省流量、保护隐私）；回前台先解锁再恢复 |
| 局域网离线 | 服务器不可达时展示上次同步的快照并标注「离线」，恢复后自动重连 |

## 4. 功能清单

> 状态列：`M1`–`M5` 为里程碑，`L1`/`L2` 为后期迭代。里程碑定义见 [`04-开发计划.md`](04-开发计划.md) §2。

### 4.1 源管理

| 功能 | 行为与规则 | 边界 | 状态 |
|---|---|---|---|
| 添加 Emby 服务器 | 选源类型 → 填地址（智能补全 `http://`，默认端口 8096）→「测试连接」探测 `/System/Info/Public` 并回显服务器名 → 账号密码登录 | 未探测成功不能进下一步 | M1 |
| 添加飞牛影视 | 同上，默认端口 8005；探测到 `ProductName` 含 fnOS 或服务器名含「飞牛」时按 Jellyfin 协议处理 | 登录方式**只有**账号密码 | M4 |
| 多服务器管理 | 增删服务器、切换当前源 | 同一时刻只显示一个源 | M5 |
| 添加本机视频目录 | SAF 选择目录并持久化授权，作为「本机」源 | 不申请 `MANAGE_EXTERNAL_STORAGE` | L2 |
| 飞牛授权式登录 | NAS 账号授权 / 扫码 / 一次性授权码 | 不阻塞账号密码路径 | L1 |
| 局域网自动发现 | **不做** | — | 不做 |

登录失败必须给出**可区分**的提示：账号或密码错误 / 地址不可达 / 端口或路径前缀不对（404）。

### 4.2 库浏览

| 功能 | 行为与规则 | 状态 |
|---|---|---|
| 库切换 | 顶部横向库 Tab（`全部` + 各库，含图标、名称、条目数）；库数 ≤5 均分不滚动，>5 横向滚动并给渐隐边缘提示 | M1 |
| 海报网格 | 2:3 海报卡 + 标题 + 观看进度角标；长按进入多选（批量标记已看 / 收藏） | M1 |
| 排序 | 支持维度：时长、文件大小、码率、分辨率、添加时间、评分、播放次数、首播年份、标题；支持「主序 + 次序」组合 | M3 |
| 筛选 | 类型（电影/剧集/集数）、演员、年份区间、分辨率区间、未看/已看/在看、收藏、源 | M3 |
| 排序筛选入口 | **合并为一个按钮**（右下角），点击弹出同一个弹层（上半排序、下半筛选）；有生效条件时按钮显示数量徽标 | M3 |
| 性能要求 | 排序 / 筛选 / 切换库在**本地已同步索引**上瞬时完成，**不出现 loading** | M3 |
| 空态 | 三分：库为空 / 未登录 / 同步中，分别给引导文案 | M1 |
| 增量分页 | 服务端增量分页加载；离线时展示上次同步快照并标注「离线」 | M1 |

### 4.3 搜索

| 功能 | 行为与规则 | 状态 |
|---|---|---|
| 中文任意位置子串 | 输入「体」能命中「三体」；不依赖空格切分、不依赖前缀 | M3 |
| 拼音全拼 / 首字母 | `santi` / `st` 都能命中「三体」 | M3 |
| 输入即搜 | debounce 200ms，无需点「搜索」按钮；过期查询被丢弃 | M3 |
| 结果排序 | 权重：标题 > 别名/原名 > 系列 > 演员/导演 > 类型/标签 > 简介；同权重再按播放次数 / 添加时间 | M3 |
| 服务端兜底 | 本地索引未命中或首次同步未完成时，回退服务端搜索并在顶部提示「本地索引仍在构建，结果可能不全」 | M3 |
| 可选增强（默认关） | 模糊音（zh↔z、n↔l、前后鼻音）；繁体/简体互搜 | M3 |
| 最近搜索 | 本地保存最近 N 条，可清空；点击回填并立即检索 | M3 |

中文搜索是**服务端固有缺陷**，因此**不做**「优先信服务端」的策略，一律以本地结果为准。

### 4.4 详情页

| 功能 | 行为与规则 | 状态 |
|---|---|---|
| 信息展示 | 海报背景 + 标题 / 评分 / 年份 / 时长 / 官方分级 → 简介 → 演职员 → 技术信息 | M5 |
| 主按钮文案 | 随观看状态变化：未看「播放」/ 在看「继续播放 · 剩 xx 分」/ 已看「再次播放」 | M5 |
| 剧集列表 | 分季 Tab + 每集缩略图 + 简介 + 观看进度条 + 已看标记；点集直接进播放器并连播 | M5 |
| 技术信息 | 容器 / 视频编码 / 音频编码 / 码率 / 分辨率 / 文件大小——**服务端条目与本机文件统一展示**，便于排查「为什么某文件播不了」 | M5 |
| 操作 | 收藏、标记已看/未看、播放方式选择（自动 / 强制直放 / 强制转码） | M5 |

### 4.5 播放

| 功能 | 行为与规则 | 状态 |
|---|---|---|
| 播放协商 | 直放优先，转码兜底；两者都不可用时明确报错而不是硬播 | M2 |
| 无卡顿 seek | 点进度条立即响应（乐观更新）、拖动过程不 seek、松手提交一次 | M3 |
| 进度条缩略图预览 | 按下即显示（≤100ms），使用预取分片，**不发起新网络请求** | M3 |
| 降级预览 | 服务端无 trickplay 时只显示时间气泡；可在设置中开启本地抽帧 | M3 |
| 字幕 | 内嵌轨 + 外挂轨（本机源自动发现同目录同名 `.srt/.ass/.ssa/.vtt`）+ 关闭；样式可调（字号/颜色/描边/边距） | M2 / L2 |
| 音轨 | 列出语言 / 声道 / 编码并切换；不支持切换的源置灰并给说明 | M2 |
| 倍速 | 0.5×–3.0×，步进 0.25×，**带音调补偿**（变速不变调） | M2 |
| **全局默认倍速** | 设置里配置默认倍速，**新建播放会话自动套用**；播放页临时改速只影响本次会话；长按画面的 2× 不写入默认值 | M2 |
| 连播 | 播至 90% 显示「下一集 + 10s 倒计时」浮层，自动连播可关闭；提供上一集/下一集按钮 | M2 |
| 画面比例 | 适应 / 填充 / 裁剪 / 原始 / 自定义缩放 | M5 |
| 手势 | 单击切控制层、双击左/右快退快进、左上下滑调亮度、右上下滑调音量、水平滑 seek、长按 2× 临时倍速 | M2 |
| 旋屏 | 跟随手机旋转自动切换（可设「自动/仅横屏/仅竖屏」），**旋转不重建播放器实例**，进度与选择不丢 | M2 |
| 系统集成 | 屏幕常亮（暂停 30s 后释放）、画中画、通知栏控制、音频焦点（被抢占自动暂停） | M2 |
| 错误与降级 | 直放失败自动切转码并提示；转码失败全屏错误卡片 + 重试；服务器离线断网占位 + 自动重连；资源不存在提供「从库中移除」 | M2 |

### 4.6 隐私与后台行为

| 功能 | 行为与规则 | 状态 |
|---|---|---|
| 应用锁 | **默认开启**：九宫格图案（至少 4 点，拒绝 Z/L/直线等弱图案），可叠加 PIN（4–8 位）与生物识别快捷解锁 | M1 |
| 触发时机 | 冷启动进入 App；从后台回前台（超过宽限期，默认立即）；手动「立即锁定」 | M1 |
| 防暴力尝试 | 连续 5 次失败起递增冷却：30s → 1min → 5min | M1 |
| 找回路径 | 设置时可配备用 PIN；未配置则仅能清除应用数据重置（需明确警告） | M1 |
| 后台暂停 | **默认切后台（含锁屏、进入最近任务）立即暂停播放** | M2 |
| 保持后台播放 | 设置项，**默认关闭**；开启后由前台服务 + 通知栏 + 画中画承载 | M2 |
| 最近任务 | 任务快照默认显示**当前播放内容**；返回 App 时回到播放器页停在当前内容，不跳回库列表 | M2 |
| 遮挡任务快照 | 设置项，**默认关闭**（仅在需要隐私保护时开启） | M2 |

### 4.7 外观

| 功能 | 行为与规则 | 状态 |
|---|---|---|
| 主题 | 只有**跟随系统 / 亮色 / 暗色**三态；默认跟随系统（深色优先，观影场景） | M1 |
| 微动画 | 所有交互都带轻量微动画（≤300ms）；系统关闭动画时退化为瞬时切换 | M1 起逐步 |
| 平板 / 折叠屏 | 由窗口尺寸驱动布局切换（`WindowSizeClass`），不新增专用代码路径 | M5 |

## 5. 关键流程

### 5.1 首次使用

```
启动 → 应用锁（首次无图案，引导设置）→ 无服务器引导页
   → 「添加服务器」→ 选源类型（Emby）→ 填地址 + 端口
   → 「测试连接」（回显服务器名，确认协议类型）→「下一步」
   → 账号 + 密码 → 登录成功
   → 拉取媒体库 → 进入库页（库 Tab + 海报网格）
```

- 首次启动时需要**引导用户设置锁屏图案**（因为应用锁默认开启且没有凭据）。
- 登录失败按三类分别提示（账号密码 / 不可达 / 端口或前缀错误），并保留已填地址便于修改。

### 5.2 日常播放

```
打开 → 图案解锁 → 库页（本地索引已就绪，瞬时展示）
   → 切库 / 排序 / 筛选 / 搜索
   → 详情页「继续播放」
   → 播放页：直放优先起播
   → 拖动进度条：预览浮层实时跟手，松手才跳转
   → 播至 90%：下一集浮层 + 倒计时 → 自动连播
   → 切后台：立即暂停并上报进度（回前台先解锁再恢复）
```

### 5.3 服务器不可达

- 展示**上次同步快照**并标注「离线」，排序与搜索仍可用（数据在本地）。
- 提供「重试」；网络恢复后自动重连并增量同步。
- 播放中的流中断时，按「重试 → 提示」处理，不静默失败。

## 7. 验收场景

每个里程碑的验收口径（DoD）见 [`04-开发计划.md`](04-开发计划.md) §2。以下是与痛点直接对应的**人工验收场景**：

| # | 场景 | 期望 | 对应痛点 |
|---|---|---|---|
| 1 | 拖动进度条 | 松手前不跳转、有缩略图预览、无约 1 秒卡顿 | 痛点 2 |

| 3 | 库内按时长/文件大小/码率/分辨率排序 | 瞬时完成、无 loading | 痛点 3 |

| 6 | 浏览与播放全程 | 无广告、无推荐位、界面精致统一 | 痛点 4 |
| 7 | 播放一个 NAS 上格式冷门的文件（DTS/TrueHD 音轨、ASS 字幕） | 要么能播，要么给出明确的不支持提示 | 痛点 1 |
